## Featured Work

### [ML Batch Prioritization System](https://github.com/paulrodriguezd/ml-batch-prioritization-system)

End-to-end batch machine learning system designed to prioritize opportunities based on predicted conversion probability.

The project focuses on leakage-free temporal feature engineering, ranking-based evaluation, MLflow model lifecycle management, and production-oriented batch scoring.

### [Conversion Propensity Modeling with GBT and PySpark](https://github.com/paulrodriguezd/conversion-propensity-gbt-pyspark)

Earlier version of a conversion propensity modeling workflow using PySpark, Gradient Boosted Trees, and MLflow.

It shows the evolution from a modeling-focused approach toward a more complete production ML prioritization system.

### [Behavioral Drift Detection for Proactive Churn Prevention](https://github.com/paulrodriguezd/Behavioral-Drift-Detection-for-Proactive-Churn-Prevention)

Behavioral monitoring system that detects early churn signals by comparing customer activity against individual history and cohort-level patterns.

The project reframes churn prevention as a proactive monitoring problem rather than a delayed prediction task.
