## Featured Work

### [Learning Analytics with dbt](https://github.com/paulrodriguezd/learning-analytics-dbt)

Runnable bronze → silver → gold pipeline in Postgres with dbt, on synthetic data.

Every metric states its population, time window and denominator; edge cases are covered by unit tests, and a data quality alert catches problems planted on purpose. CI runs the full build on every pull request.

### [ML Batch Prioritization System](https://github.com/paulrodriguezd/ml-batch-prioritization-system)

End-to-end batch machine learning system designed to prioritize opportunities based on predicted conversion probability.

The project focuses on leakage-free temporal feature engineering, ranking-based evaluation, MLflow model lifecycle management, and production-oriented batch scoring.
